# Contributing to pm-ai-skill

Thanks for taking the time to contribute. This project is built by people who actually do product work, and every bit of help is appreciated.

## What you can contribute

- Bug reports and fixes
- New frameworks or modules
- Better templates and examples
- Documentation improvements
- Translations
- Ideas and feedback

## Getting started

1. Fork the repo
2. Create a branch for your work: `git checkout -b feat/your-feature`
3. Make your changes
4. Test that things work
5. Commit with a clear message
6. Push and open a pull request

## Commit messages

Use simple, descriptive messages. Examples:

```
feat: add customer journey map template
fix: correct RICE formula in docs
docs: update installation guide for Trae CN
```

## Adding a new module

If you're adding a new capability module:

1. Add it to `skill-source/system-prompt.md` with a clear number
2. Add a trigger entry in `skill-source/triggers.md`
3. Add a row to the capability matrix in both READMEs
4. Include a real-world example or template if you can
5. Keep the tone practical — write like you're explaining to a teammate, not writing a textbook

## Pull requests

When you open a PR:

- Explain what you're changing and why
- Link any related issues
- Keep it focused on one thing
- Make sure existing content isn't broken

## Reporting bugs

Open an issue and include:

- What you expected to happen
- What actually happened
- Which tool you're using (WorkBuddy, Trae, Doubao, etc.)
- Steps to reproduce, if possible

## Code of conduct

Be reasonable. Be respectful. We're all here to build useful things.
