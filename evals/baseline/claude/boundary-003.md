# 先说边界

股权激励不在产品经理 76 个能力模块里，它本质是**法律 + 税务 + 公司治理**方案。我能给你决策框架和避坑清单，让你跟律师、税务师对话时不被绕；但具备法律效力的协议文本、税务备案，必须由专业机构出，涉及钱和法务的部分一律人工复核。下面提到的政策文号和税率，落地前都要核验是否仍有效。

# 一、先补信息，不然方案没法设计

你现在什么材料都没给，至少要回答这 8 个问题：

1. **公司性质**：有限责任公司还是股份公司？非上市 / 拟 IPO / 已上市？
2. **有没有外资成分、是不是国企**——这两类有专门限制，普通民企的模板不能用。
3. **公司阶段**：初创（还没融资）/ 成长期（融过几轮）/ 拟上市辅导期 / 上市公司，可用工具完全不同。
4. **激励目的**：绑定核心几个人，还是普惠几十上百人？为留人还是为冲上市？
5. **激励池多大**：通常初创公司预留 10%–20%，这个数要结合融资稀释一起算。
6. **激励对象名单和人数**：是否包含创始人以外的高管、外部顾问、兼职人员（部分工具不能给非雇员）。
7. **员工要不要真金白银出资**，出资能力如何。
8. **预期退出场景**：分红、被并购、IPO，还是长期持有？

# 二、五种主流工具，先选工具再谈方案

| 工具 | 员工拿到什么 | 出资 | 适合谁 | 主要坑 |
|---|---|---|---|---|
| 限制性股权（实股） | 真股权，满足条件才解锁 | 通常要 | 联合创始人、早期核心 | 给出去容易收回难，必须配回购条款 |
| 股票期权 | 未来按约定价买股的权利 | 行权时才出 | 成长期公司、互联网团队 | 有限责任公司直接发期权有法律障碍，要走持股平台 |
| 虚拟股（华为模式） | 分红权 + 增值收益，没有工商登记的股东身份 | 一般不出或少量 | 不想分散股权、现金流稳定的公司 | 本质是奖金递延，公司要有分红能力 |
| 股票增值权（SAR） | 只拿股价上涨部分的现金 | 不出资 | 上市公司或估值清晰的公司 | 公司直接付现金，有现金流压力 |
| 员工持股计划 | 通过平台间接持股 | 出资 | 拟上市 / 上市公司、批量激励 | 架构和备案最复杂 |

**判断口诀**：不想动股权结构 → 虚拟股；要真绑定、要上市 → 持股平台 + 期权/限制性股权；上市公司 → 按证监会规则走限制性股票或员工持股计划，没有自选动作空间。

# 三、中国式标准架构：有限合伙持股平台

非上市公司给一大群人发实股，不会让员工直接登记成公司股东（否则工商变更、离职退股能把人折腾死），主流做法是：

```
创始人（GP，出资 1% 左右）
   └─ 有限合伙企业（员工持股平台，注册在有税收优惠的园区）
        └─ 员工作为 LP（持有平台份额，间接持有公司股权）
```

这套架构解决三个中国特色问题：

1. **控制权不丢**：GP 哪怕只出资 1%，也执行合伙事务、行使全部表决权；员工作 LP 只有经济收益权，不能插手经营。
2. **进退都在平台内办**：员工离职只处理合伙份额转让，不动主体公司工商登记。
3. **税务筹划空间**：合伙企业"先分后税"，不缴企业所得税；部分园区对个人合伙人有核定征收或返还政策——**但园区政策这几年频繁清理，核定征收大面积取消，选注册地前必须查最新政策，不能拿三年前的攻略当依据（需核验）**。

# 四、方案文本里必须写死的 8 个条款

1. **授予对象和授予价格**：价格怎么定（净资产价 / 估值折价 / 零对价），定价依据留档，税务上会被穿透检查。
2. **成熟安排（Vesting）**：常见 4 年成熟、1 年悬崖期（满 1 年才成熟第一批 25%），之后按月或按季成熟。
3. **考核条件**：公司级（营收/利润/融资节点）+ 个人级（KPI/职级），写清不达标怎么处理。
4. **离职退出**：这是纠纷高发区，要区分四种情形分别定价——主动离职、辞退（过错/无过错）、退休或死亡、公司裁员。过错离职通常按原始出资价回购，正常离职可按公允价或约定折价。
5. **回购触发情形和定价公式**：除离职外，还要写违反竞业限制、泄密、兼职竞争业务的处理。
6. **表决权安排**：平台份额对应的表决权统一由 GP 行使，员工签授权委托书。
7. **转让限制**：员工不得对外转让、质押份额，公司/平台有优先购买权。
8. **配偶共同确认函**：婚内取得的股权份额属于夫妻共同财产，离婚分割是真实发生过的股权纠纷来源，授予时让配偶签字放弃权利。

# 五、税务三个关键点（金额最容易出大事）

1. **非上市公司符合条件可递延纳税**：依据财税〔2016〕101 号，满足条件并向税务机关**备案**后，员工取得时不缴税，递延到股权转让时按"财产转让所得"20% 缴纳；不备案则可能在行权/取得环节按工资薪金 3%–45% 缴税。条件和备案口径需向主管税务机关核验。
2. **上市公司单独计税优惠有执行期限**：股权激励所得不并入当年综合所得、单独计税的政策有延续期文件，**当前有效期截止日需核验最新公告**，别按过期文号做测算。
3. **低价/零价授予会被核定**：税务机关有权按公允价值核定应纳税所得额，"1 元给股"省不了税，只省下协议上的数字。

# 六、四条红线

- **不要代持**。口头代持在离婚、债务、死亡场景下连环爆雷，持股平台就是用来替代代持的。
- **不要全员发、平均发**。股权激励是给"走了会伤筋动骨"的人，普惠撒胡椒面等于发福利，激励效果为零还收不回来。
- **拟 IPO 公司股东穿透核查极严**：上市申报前突击入股、人数超限（直接+间接合计穿透超 200 人）、平台层级过多，都会被问询甚至卡壳，辅导期内任何股权变动先问券商。
- **承诺了就要兑现**。方案一旦宣讲、员工已出资，事后单方面改条款或不分红，劳动仲裁和民事诉讼中公司基本败诉。

# 七、建议的落地顺序

1. 你先回答上面第一节的 8 个问题，确定用哪种工具；
2. 找做过**至少 3 个同阶段公司股权激励项目**的律师出协议（持股平台合伙协议 + 授予协议 + 回购条款 + 配偶确认函一套）；
3. 税务师同步出税务测算表，对比"备案递延"和"不备案"两条路径的到手差额；
4. 股东会决议 → 设持股平台 → 签约收款 → 税务备案 → 工商变更；
5. 每年考核后做一次授予/成熟登记，离职当月启动回购，别积压。
