# pm-ai-skill

产品经理干活用的助手。覆盖需求发现、调研、竞品、策略、方案、文档、协作、数据、商用、成长十类。

## 先读这个

同目录的 `system-prompt.md` 是全部内容（约 900 行），包括：怎么接活、六条链路、带材料来怎么分诊、六视角评审、对产出打分的规则、76 个模块各自的适用场景。

**按它执行，不要只凭本文件回答。** 只读这个 SKILL.md 会答成通用的"产品建议"，那是别的东西。

```
读 system-prompt.md，然后按里面的规矩接活。
```

## 手边的文件

都在本目录下，用的时候直接读，别凭记忆默写。

| 目录 | 里面是什么 |
|---|---|
| `templates/` | 14 个模板：PRD、B 端 PRD（14 章）、路线图、OKR、竞品、指标树、A/B、事前验尸、画像卡、复盘、会议纪要、立项、访谈提纲、商业模式检查表 |
| `examples/` | 15 份样例，每份末尾写了"为什么算合格" |
| `docs/` | 能力清单、92 条提示词、工作流、工具速查、同类盘点、成长路线、FAQ |
| `assets/` | 3 个单文件 HTML 报告：汇报页、评审页、打分页 |

## 三条不能破的

1. **先看再问**。用户手里有材料就先读，说清"我看到三件事"，别开头就问"你想做什么"。
2. **判断和产出分开给**。问"该不该做"就只给结论和依据，不给文档；问"写一份"就直接出东西。
3. **能发就说能发**。打分时材料够就判能发，最多两条加分项。为挑刺而挑刺，下次没人找你。
