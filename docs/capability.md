# PM-AI-Skill 能力清单

整合 10 大 PM 工作能力，一个 Skill 覆盖全链路。

## 1. PM 工具箱（Product Manager Toolkit）
- **RICE 优先级排序**：Reach × Impact × Confidence ÷ Effort，输出得分与排序。
- **用户访谈解析**：输入访谈文本，提取痛点 / 爽点 / 痒点。
- **需求探索框架**：Kano、Jobs-to-be-Done、第一性原理。
- **上市策略**：GTM 草案、目标人群、渠道假设。

## 2. 竞品分析（Competitive Analysis）
- 直接 / 间接竞品挖掘。
- 功能对比矩阵、定位象限、定价带、用户情绪分析。
- 输出市场空白假设。

## 3. 用户研究（User Research）
- 问卷设计：规避引导性、双重提问。
- 探索 / 验证两种访谈脚本。
- 反馈主题聚类与情感分析。

## 4. 数据分析（Data Analysis）
- CSV 数据清洗、缺失值与格式异常检查。
- 描述统计、趋势检测、异常点识别。
- 业务解读，不执行 SQL / Python。

## 5. PRD Writer（PRD 结构化教练）
- 强制填写业务目标、成功指标、失败回退条件。
- 逻辑一致性校验、异常流程与边界条件提醒。
- 只做框架教练，不代笔业务内容。

## 6. Meeting Minutes（会议纪要）
- 输出：会议元信息、决策（带上下文）、行动项（负责人 + deadline + 优先级）、待确认项、下次议程。

## 7. Mind Map（思维导图）
- Markdown / 文本大纲转思维导图结构。
- 逻辑冲突、循环依赖检测。
- 多方案水平并排对比。

## 8. Product Framework（产品架构）
- 业务分层：表现层 / 业务层 / 数据层。
- 核心能力 vs 可外包能力区分。
- MVP 规划与路线图。

## 9. Socratic Business Model Canvas（苏格拉底商业模式画布）
- 不直接填空，层层追问。
- 识别未验证假设，区分已验证 / 待验证清单。

## 10. Excalidraw 可视化
- 痛点场景图、价值主张图、功能架构图、用户旅程图。
- 输出可直接粘贴到 Excalidraw 的结构描述，支持导出 PNG / SVG。
