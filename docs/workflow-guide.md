# 分阶段工作流指南

把 PM-AI-Skill 嵌入到产品经理日常工作流中。

## 阶段 1：需求探索
- 触发：发现一个问题 / 收到一个需求。
- 用 Skill：
  - 用户研究：设计问卷 + 访谈脚本。
  - 苏格拉底商业模式画布：校验问题是否成立。
- 产出：问题定义、用户痛点假设。

## 阶段 2：调研与定位
- 用 Skill：
  - 竞品分析：找直接 / 间接竞品，做定位象限。
  - Product Framework：梳理业务分层。
- 产出：竞争格局图、定位假设。

## 阶段 3：方案设计
- 用 Skill：
  - Mind Map：把思路转成结构化大纲。
  - Excalidraw：画痛点场景、价值主张、功能架构、用户旅程。
- 产出：方案草图、流程图。

## 阶段 4：PRD 输出
- 用 Skill：
  - PRD Writer：搭框架，强制填业务目标、成功指标、回退条件。
- 产出：可评审的 PRD 草稿。

## 阶段 5：排期与协作
- 用 Skill：
  - Meeting Minutes：评审会、对齐会输出行动项。
- 产出：会议纪要、行动项跟踪表。

## 阶段 6：上线与验证
- 用 Skill：
  - Data Analysis：CSV 看数据趋势与异常。
  - RICE：根据上线数据复盘，决定下一轮优先级。
- 产出：数据复盘报告、下一轮 Backlog 优先级。

## 一句话原则
> Skill 是思考教练，不是答案机器。每次输出后，问自己一句："这个结论有业务数据支撑吗？"
