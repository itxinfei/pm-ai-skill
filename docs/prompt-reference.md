# 提示词参考库

> 直接复制使用，把 `xxx` 替换成你的业务内容。

## 需求优先级（RICE）
```
使用 RICE 模型评估以下需求，并按得分排序：
1. xxx
2. xxx
3. xxx
输出表格：Reach / Impact / Confidence / Effort / 得分 / 排序，并给出每一项的取值理由。
```

## 用户研究
```
帮我设计一份针对【老功能使用率低】的问卷 + 深度访谈脚本。
要求：
- 问卷 15 题以内，避开引导性、双重提问；
- 访谈脚本 30 分钟，含暖场、行为、痛点、验证四段；
- 输出可直接发给用户的版本。
```

## 竞品分析
```
分析【XX 垂直赛道】的竞争格局：
- 列出 Top 5 直接竞品 + 2 个跨界替代者；
- 做定位象限（价格 × 目标人群）；
- 对比核心功能差异；
- 找出 3 个市场空白机会。
外部数据请标注"需人工核验"。
```

## PRD 辅助
```
基于业务目标：【提升新用户首单转化 15%】，生成 PRD 结构化框架。
必须包含：
- 背景与问题；
- 成功指标（含现状、目标值、观测周期）；
- 非目标（本期不做什么）；
- 异常流程与边界条件；
- 回退条件与灰度计划。
不要编造业务数字，缺数据的地方留空让我填。
```

## 会议纪要
```
把下面会议录音转写文本整理成结构化纪要，保留决策上下文：
【粘贴文本】
输出：
1. 会议元信息；
2. 决策表（编号 / 决策 / 上下文 / 拍板人）；
3. 行动项表（编号 / 内容 / 负责人 / 截止时间 / 优先级）；
4. 待确认项；
5. 下次会议建议议程。
```

## 思维导图
```
把下面会员体系重构大纲转成思维导图结构，并检查逻辑冲突：
【粘贴大纲】
输出缩进式 Markdown，并列出发现的冲突点。
```

## 产品架构
```
基于【B 端 SaaS 客服系统】场景，输出产品业务架构：
- 表现层（用户端 / 管理端 / 开放 API）；
- 业务层（核心能力模块）；
- 数据层（埋点 / 业务库 / 数仓）；
- 区分核心能力与可外包能力。
```

## 商业模式画布（苏格拉底式）
```
用苏格拉底追问模式校验这个创新项目的商业模式：
【粘贴项目描述】
不要直接填空，先对每个模块追问，最后输出：
- 已验证假设清单；
- 待验证假设 Top 3；
- 对应的验证方式。
```

## Excalidraw 绘图
```
把下面业务思路生成 4 张 Excalidraw 图：
1. Why 痛点场景图；
2. What 价值主张图；
3. How 功能架构图；
4. 用户旅程图（阶段 / 触点 / 情绪 / 痛点 / 机会）。
输出可直接粘贴到 Excalidraw 的结构描述。
```

## 数据分析
```
对这份 CSV 做数据健康检查 + 趋势 / 异常分析：
【粘贴 CSV 或描述字段】
输出：
- 数据质量（缺失 / 异常 / 格式）；
- 关键指标趋势；
- 异常点与业务解读；
- 下一步建议分析方向。
```
