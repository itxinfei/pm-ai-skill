# 商业模式假设校验清单（苏格拉底式）

> 用法：不要直接填空，先回答每个问题下面的追问。区分"已验证"和"待验证"。

## 1. 客户细分
- [ ] 我们服务谁？
- 追问：谁最痛？谁最愿意付钱？我们凭什么判断？（访谈 / 数据 / 直觉）
- 状态：已验证 / 待验证

## 2. 价值主张
- [ ] 我们替客户解决了什么核心问题？
- 追问：是"真问题"还是"我们以为的问题"？客户自己说过吗？
- 状态：已验证 / 待验证

## 3. 渠道通路
- [ ] 怎么触达客户？
- 追问：CAC 是多少？这个渠道可规模化吗？
- 状态：已验证 / 待验证

## 4. 客户关系
- [ ] 客户为什么留下来？
- 追问：留存曲线是什么样？换走的代价是什么？
- 状态：已验证 / 待验证

## 5. 收入来源
- [ ] 客户为什么付钱？付多少？
- 追问：定价是成本加成、竞品对标、还是客户出价？复购率？
- 状态：已验证 / 待验证

## 6. 核心资源
- [ ] 我们凭什么做成这件事？
- 追问：这个资源是独占的吗？别人能不能抄？
- 状态：已验证 / 待验证

## 7. 关键业务
- [ ] 我们每天 / 每月必须做对的事是什么？
- 追问：哪一步做砸了整个模型就崩？
- 状态：已验证 / 待验证

## 8. 重要合作
- [ ] 谁是我们离不开的伙伴？
- 追问：他们会不会反过来卡我们？
- 状态：已验证 / 待验证

## 9. 成本结构
- [ ] 最大的三块成本是什么？
- 追问：规模上去后，单位成本是降还是升？
- 状态：已验证 / 待验证
